# Wanderly | AI-Powered Travel Planner

Welcome to **Wanderly**, a modern travel planning platform developed by **Mohamed Sameh**. This project showcases a high-performance web interface for searching and booking flights, hotels, and trips.

## 🚀 Features
- **Smart Search:** Advanced filtering for flights and hotels.
- **Multilingual Support:** Full Arabic and English integration.
- **Responsive Design:** Optimized for all devices using Tailwind CSS.
- **AI-Ready:** Built with a scalable architecture for future AI integration.

## 🛠️ Tech Stack
- **Frontend:** React.js, TypeScript, Tailwind CSS.
- **UI Components:** Shadcn/ui, Lucide Icons.
- **Internationalization:** i18next (Arabic/English).
- **Deployment:** Netlify.
